隐私说明

你的笔记，只留在你的浏览器中。

本说明适用于留白笔记 v1.0.0，更新日期为 2026-10-14。

收集与传输

扩展不要求注册，不收集姓名、邮箱或设备标识，不包含分析、广告或远程请求代码。笔记不会由扩展主动发送到任何服务器。

本地存储

标题、正文、置顶状态和时间信息使用浏览器扩展页面的 localStorage 保存。数据仅供该扩展在当前浏览器配置中读取。

权限

v1.0.0 不声明任何浏览器权限。点击工具栏图标时，扩展只打开自身页面，不读取当前标签页内容。

数据删除与风险

删除笔记会立即从本地存储移除且无法恢复。卸载扩展、清除扩展数据、更换浏览器配置或设备也可能造成全部笔记丢失。当前版本不提供云同步或备份。

反馈

可通过项目 GitHub Issues 提交隐私或功能问题。
